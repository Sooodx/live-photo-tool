# 内置风格 LUT 的来源与许可

这些 33³ 3D LUT 由 DAEDAL 发布，输入为已校正的 Rec.709 SDR。每个 `.cube` 均保留 `packs-v1` 发布包中的原始内容。[DAEDAL v1 发布页](https://github.com/luciansofronie/daedal-downloads/releases/tag/packs-v1)

DAEDAL 将这些 LUT 数据置于 CC0 1.0 Universal 下，明确允许商业使用和再分发，无须另行授权或署名。两个压缩包提供同一份许可证声明，原文随仓库和镜像分发。[包内许可证](LICENSE.txt) · [DAEDAL 资产条款](https://daedal.art/terms/) · [CC0 1.0 正文](https://creativecommons.org/publicdomain/zero/1.0/legalcode.en)
